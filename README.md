# 🔐 CodeCrack — Caesar Cipher

CodeCrack is a beginner-friendly Python project that encodes and decodes secret messages using the **Caesar Cipher technique**.

This project helped me practice Python functions, loops, conditions, strings, and basic problem-solving.

## ✨ Features

- Encode messages by shifting letters forward.
- Decode messages by shifting letters backward.
- Preserve uppercase and lowercase letters.
- Keep spaces, numbers, and punctuation unchanged.
- Choose operations using a simple menu.
- Validate the user's choice and shift range.

## 🛠️ Technologies Used

- **Language:** Python
- **Concepts:** Functions, strings, loops, conditional statements, user input, string indexing, and the modulo operator (`%`).

## 🚀 How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

   ```bash
   python main.py
   ```

## 💻 Example

**Input:**

```text
Enter choice: 1
Enter message: HELLO
Enter shift (0-25): 3
```

**Output:**

```text
Encoded message: KHOOR
```

To decode the message, select option `2` and enter `KHOOR` with a shift value of `3`.

**Decoded output:**

```text
HELLO
```
